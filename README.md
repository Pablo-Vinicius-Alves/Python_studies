# Cronograma de Estudos — Python do Zero ao Avançado (foco em Ciência de Dados)

## Este repositório tem como objetivo mostrar minha evolução programando em Python. 🪜
 
**Regra geral:** nenhuma fase deve ser considerada concluída sem o projeto prático correspondente entregue. 

 
## Fase 0 — Preparação: ✔️
 
- Instalar Python (Anaconda).✅
- Configurar VS Code + extensão Python.✅
- Aprender a rodar o código Python no terminal.✅
- Primeiro: "Olá Mundo!".✅
 
## Fase 1 — Fundamentos da Linguagem: 
 
**Sintaxe básica** ✔️
- Variáveis, tipos de dados (int, float, str, bool).✅
- Operadores aritméticos, lógicos e de comparação.✅
- Estruturas condicionais (if/elif/else).✅
- Loops (for, while) e controle de fluxo (break, continue).✅
- Input/output básico.✅

**Estruturas de dados nativas**
- Listas, tuplas, dicionários, sets
- Compreensão de listas e dicionários (list/dict comprehension)
- Manipulação de strings (métodos, slicing, formatação com f-strings)
- Funções: parâmetros, retorno, *args, **kwargs, escopo de variáveis

**Consolidação**
- Tratamento de erros (try/except/finally)
- Leitura e escrita de arquivos (txt, csv básico)

**Projeto 1:** um programa de linha de comando funcional (ex: gerenciador de tarefas, conversor de unidades, jogo simples). Sem bibliotecas externas.
